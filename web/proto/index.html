Workbench mockups

The same static screen (White scope, Removal selected, 25 Foundations cards) built on four open-source design systems. No engine: the data is hard-coded.

  • Web Awesome 3.15.0: free components from the official CDN; wa-tree, wa-page drawer, radio-button chips with wa-progress-ring, hand-built table (the data grid is Pro).
  • IBM Carbon Web Components 2.68.0: official IBM CDN; UI shell side nav, cds-tree-view, cds-tabs, cds-table with built-in sort, selection and search.
  • React Aria Components 1.22.1 (React): behaviour and ARIA only, every style written for this page; Tree, Table with sort and row selection, TagGroup chips, Breadcrumbs with Menu, Switch, modal sheet for the tree on narrow screens.
  • Mantine 9.8.2 (React): AppShell with burger drawer, Tree, Chip.Group with RingProgress, Breadcrumbs with Menu, Badge, Switch; plain Table with hand-written sorting.
